# 20 ежедневных черновиков и публикаций @ter_cars

**Статус:** утверждено владелицей 04.11.2026: готовить до 20 черновиков на день; каждый оставленный пост публикуется только после отдельного «ОК», максимум 20 за сутки.

## Поведение

- GitHub Actions каждый день в 15:00 МСК запускает GitHub Copilot CLI, читает правила и материалы репозитория и создаёт черновики на следующий день. Отдельный ручной запуск принимает дату для проверки.
- Перед генерацией workflow собирает свежие сигналы за последние 72 часа из публичных превью Telegram «Дром» и «Автопоток», ленты Пикабу «Авто» и RSS «За рулём». Снимок живёт только на runner и попадает в контекст генерации; исходники не копируются в репозиторий.
- Сборщик учитывает `robots.txt` и `Crawl-delay` для Пикабу. Если доступно меньше пяти свежих сигналов из минимум двух типов источников, workflow завершается ошибкой и черновики не создаёт. Недоступные сайты не считаются доказательством отсутствия обсуждений.
- Для новостных постов валидатор требует прямую ссылку на запись из сегодняшнего live-снимка. Live-сигналы можно использовать для идей других рубрик, не приписывая чужие истории Маше.
- Генерация идёт через временный `GITHUB_TOKEN` и разрешение `copilot-requests`; долгоживущий ключ модели в секретах не хранится. Для этой учётной записи GitHub Copilot CLI должен быть доступен; при отсутствии доступа задача завершается ошибкой и не пишет черновики.
- Copilot CLI не получает инструменты чтения/записи файлов, shell, сети или памяти. Контекст передаётся в запросе, JSON проверяется локальным валидатором, в Git коммитится только `drafts/<дата>.json`.
- Генератор создаёт 20 вариантов на день. Владелица пропускает неподходящие варианты и отдельно одобряет каждый пост, который должен выйти.
- Одобрение одной карточки не одобряет остальные. Пропущенные и не одобренные посты не публикуются.
- Для публикации задаются 20 слотов: 06:00, 06:50, 07:40, 08:30, 09:20, 10:40, 11:30, 12:20, 13:10, 14:00, 14:50, 15:40, 16:30, 17:20, 18:10, 19:00, 19:50, 20:40, 21:30, 22:20 МСК.
- Сохраняется тихое окно 09:50–10:20. Между слотами не менее 50 минут; случайная задержка публикации 1–6 минут не сокращает фактический интервал ниже 45 минут.
- Новая настройка действует с 05.11.2026. Исторические дни сохраняют прежние количества и тексты.

## Текущая граница и риск

Пульт уже публикует только карточки со статусом «ОК» и поддерживает индивидуальный пропуск. Изменение увеличивает предел расписания с 4 до 20 публикаций в день; автоматическая публикация без отдельного одобрения не добавляется. Workflow генерации только создаёт черновики; он не меняет статусы карточек и не запускает публикацию.

Meta рекомендует 2–5 публикаций в неделю для роста аудитории. Запрошенные 20 в день существенно выше этой рекомендации и могут ухудшить охваты или вызвать ограничения платформы. Это рекомендация Meta, не заявленный технический лимит. Источник: https://about.fb.com/news/2024/10/find-your-community-with-new-threads-educational-insights/.

## Реализация

Изменить `config.json` и валидатор, добавить сборщик live-источников и передавать его снимок в генератор Copilot для GitHub Actions. Workflow сохраняет ежедневное расписание с 05.11.2026 и допускает ручную проверку live-сбора без генерации. Обновить инструкцию, чтобы она однозначно описывала индивидуальное одобрение и пропуск. Генератор проверяет JSON и ссылки на новости перед записью; пульт использует настройки конфигурации динамически, поэтому его код и страница не меняются.
